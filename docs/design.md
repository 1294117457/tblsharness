用户感觉自己在“画图”，但底层改的是模型。图和模型是**同步的两种表示**，模型是源



1. **自己定义模型层**：用一个独立的 JSON/YAML Schema 描述表、字段、关系、约束。这是你的“唯一真相源”。
2. **设计阶段**：做一个轻量编辑器，用户拖拽/表单操作 → 修改模型 → 派生 PlantUML 渲染给人看。
3. **开发阶段**：用 dbclient 类似的能力（连接数据库、读取 Schema）作为**输入**，把数据库实际结构反向同步到模型层。但这一步是“模型更新”，不是“模型被数据库替代”。
