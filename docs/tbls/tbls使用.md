## 一、5 个子命令

| 命令            | 作用                                                         | 和你的工具的关系                                             |
| :-------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| `tbls doc`      | 生成 Markdown 文档和 ER 图（svg），顺带输出 `schema.json`    | 你已经用过；可以生成设计模型和开发模型的文档                 |
| `tbls out`      | 按指定格式输出到单个文件：json、yaml、mermaid、plantuml、dot、svg、png、xlsx、md、config | 最关键。插件主要用 `out -t json` 获取数据库结构              |
| `tbls diff`     | 对比数据库和已生成的文档，或者两个数据库之间对比             | 只能对比 Markdown 文本，太粗，不适合直接用，但可以参考它的思路 |
| `tbls lint`     | 按规则检查数据库，比如缺注释、缺索引、字段过多               | 可以直接用于治理检查                                         |
| `tbls coverage` | 统计注释覆盖率                                               | 可以作为文档完整度指标                                       |
