**同步规则（实际实现）**：

- 范围：图里画出的实体 + frontmatter `refs`（上次同步时图里有的表）。`refs` 里有、图里没画的表才建议删除，所以 AI 只写几张表不会误删别的表。
- 默认勾选：新增、修改勾选；删除表、删除字段、删除关系、去掉主键/唯一**不勾选**。
- 依赖：例如"新增关系"依赖"新建表"，勾选前者会自动勾上后者，取消后者会自动取消前者；应用时再校验一次。
- 没有字段块的实体（只写 `orders`）表示"只是引用"，不比较字段，也不会建议删字段。
- 外键字段推断顺序：关系标签里写的字段名 → `<父表单数>_id` / `<父表单数>Id` → 推断不出时让你在下拉框里选（标了 FK 的字段排在前面）。已有唯一一条同方向关系时直接匹配。
- 多对多只允许 `json_array`，其他写法列为问题，不生成同步项。
- Mermaid 表达不了的内容（默认值、索引、enum、关系说明、多态的类型字段）同步时保留原值。
- 应用前按当前文本重新检测，面板过时时提示"设计图已经变化"而不是写入旧结果。删表会再弹一次确认。
- 忽略：写入 frontmatter `ignored`，面板底部可以"恢复"。

## 四、验收清单（请在 Cursor 里走一遍）

1. 新建一个空设计库 → 点"表结构"打开画布 → 空状态出现两个按钮。
2. 点"新建 ER 图" → 编辑器打开，左边有示例注释 → 复制给 AI → 在对话里让 AI 设计"用户、订单、退款"三张表 → 把 ER 图粘回左边 → 中间出图，右边列出新建表和关系 → 同步 → 画布出现三张表。
3. 在画布"待同步"页签看不到内容（已同步）；在编辑器里删掉一个字段 → 右边出现"删除字段"但默认不勾选。
4. 编辑器里点"撤销上次同步"；在画布"待同步"里同步后按 Ctrl+Z。
5. 用"以文本打开"直接改 `.md` 文件，编辑器和右侧差异跟着变；直接在 VS Code 里改文件时编辑器里的光标不跳、不吞字。
6. 把一张表的外键字段名改成推断不出的名字 → 右侧出现下拉选择。
7. 属性面板"快速添加字段"输入 `email varchar(128) not null unique 登录邮箱`，按 Enter；点 created_at 模板。
8. 暗色 / 亮色主题下 Mermaid 预览是否清楚。
9. 旧设计库（`ext.json` 里有 `modules`）：随便改一处表结构后，`schema.json` 里出现 `viewpoints`，`ext.json` 里的 `modules` 消失。

### 5.2 设计要点

- **同步项结构不变**：每种图各自产出 `SyncItem[]`，`SyncPanel`、忽略、依赖、重新检测、撤销全部复用。`DIAGRAM_TYPES` 的 `syncable` 按类型打开。
- **只解析需要的部分**：流程图 / 时序图只提取节点 ID、显示文字和形状，不做完整语法解析；解析不了的行跳过，不报错，预览照常由 mermaid.js 渲染。
- **agent 边界不变**：AI 只写设计图，表结构只通过右侧面板由用户确认修改；`refs` 可以由 AI 改，`bind`、`ignored`、`layout` 不让 AI 改（规范里写明；"复制给 AI"时不附这几个字段）。
- **枚举的存储**：PostgreSQL 用 `schema.enums` + 字段类型引用枚举名；MySQL 直接写在字段类型里 `enum('a','b')`。枚举编辑和状态图同步对两种写法都要支持（见问题 1）。
- **安全**：新增的任何给 AI 的内容（包括 tbls JSON）只来自设计库，不读数据库快照；设计库的 JSON 里没有连接信息，但仍要过一遍检查，确保不会带出 `source.yml` 或数据库显示名。

### 5.3 开工前需要确认

1. **枚举写法**：状态图绑定的字段，枚举值存在哪里？
   - 建议：按设计库的库类型自动选。PostgreSQL 存在 `schema.enums`；MySQL 写在字段类型 `enum(...)` 里；其他库没有枚举类型，存在 `ext.json` 的 `enums` 里，只用于设计，不影响字段类型。
2. **流程图 / 时序图里怎么认出"这是一张表"**：
   - 建议：数据流图里 `[(orders)]`（圆柱形，数据存储）表示表；时序图里 ID 和表名完全一致的参与者表示表；流程图不认表，只靠 `refs`。
3. **表改名后替换 Mermaid 正文**：默认勾选直接替换，还是默认不勾选？
   - 建议：默认勾选。只替换实体名、关系两端和 `refs`，不改注释和说明文字。
4. **撤销**：设计图编辑器保持"撤销上次同步"按钮（3.3 #8），还是需要保留多次？
   - 建议：改成保留最近 10 次，每次都校验表结构之后没有被别处改过。
